# utkuumut portfolio

Statik, iki dilli kişisel portfolyo sitesi. Sunucu veya veritabanı gerektirmez ve GitHub Pages ile doğrudan çalışır.

## GitHub Pages'ta yayınlama

1. GitHub'da yeni ve herkese açık bir depo oluştur.
2. Bu klasördeki `index.html`, `styles.css`, `script.js` ve `assets` klasörünü deponun ana dizinine yükle.
3. Deponun **Settings → Pages** bölümünü aç.
4. **Build and deployment** altında **Deploy from a branch** seçeneğini seç.
5. Dal olarak `main`, klasör olarak `/ (root)` seçip kaydet.

GitHub birkaç dakika içinde site adresini aynı ekranda gösterecektir.

## Yeni proje ekleme

`index.html` içindeki `work` bölümünde bulunan geçici kartı, proje görselleri ve bağlantıları hazır olduğunda proje kartlarıyla değiştirebilirsin.
